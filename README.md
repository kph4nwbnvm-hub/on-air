# على الهوا (On Air)

- `index.html` — اللعبة كاملة في ملف واحد. افتحه بالمتصفح (Chrome أو Edge) ليعمل على الكمبيوتر.
- `src/` — الكود المصدري: `main.js` (اللعبة)، `char.js` (الشخصيات)، `i18n.js` (اللغات والنصوص)، `template.html` (الواجهة).
- للبناء من المصدر: `npm install` ثم `bash build.sh`، والناتج في `dist/index.html`.
